# 美股基金估值

实时追踪美股基金估值变动，支持盘中、盘前/盘后全时段监控。

访问地址：https://fund-valuation-m37d.onrender.com/

## 功能特性

- 实时估值：基于基金持仓和美股行情计算基金估值涨跌幅
- 美股24小时：盘后/盘前实时估值，不错过任何波动
- VIXY恐慌指数：4级渐进提醒（关注/逐步买入/加大仓位/重仓买入）
- 多市场覆盖：支持美股、港股、A股、韩股持仓
- 汇率联动：自动计算USD/CNY汇率对基金净值的影响
- 日夜模式：跟随系统自动切换，富途牛牛风格界面
- 智能首页：北京时间5:00-15:00显示盘后列表，15:00-次日5:00显示24小时实时页

- 前端：原生HTML/CSS/JS单页应用

## 分时追涨闸门与走弱预警（159509）

详情页分时图上方新增一张卡片，只回答一件事：**现在这个价能不能追**。

- 追涨闸门：时间 < 14:30、开盘涨幅 ≤ 0.8%、现价站上分时均价、偏离均价 ≤ 0.6%。任一不满足就判「不能追」，并给出需要回踩到的均价价位。
- 走弱减仓：连续 3 分钟收在分时均价下方 0.3% 且近 4 分钟跌幅 ≥ 0.3% → 「持续走弱」；再破前段支撑或近 4 分钟跌幅 ≥ 0.8% → 「破位」。信号只看已闭合分钟，确认后下一分钟才提示。

口径检验脚本（数据自动缓存到 `data/intraday-study.json`）：

```bash
node scripts/intraday-chase-study.js --refresh          # 重新抓分钟数据并输出分层报告
node scripts/intraday-chase-study.js --day 2026-11-09   # 回放指定交易日
```

结论仅基于单一标的约 41 个交易日、不含历史溢价数据，阈值用于判断方向，不构成收益承诺。

## 部署

```bash
npm install
node server.js
```

服务默认运行在 `http://localhost:3000`。

## 数据说明

- 持仓数据来源于基金季报/年报公开披露
- 行情数据5秒自动刷新
- 盘后/盘前价格通过新浪财经接口获取
- 估值仅供参考，不构成投资建议
